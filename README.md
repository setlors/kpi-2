# Домен: Трекер тренувань

Застосунок для запису тренувань: користувач фіксує, коли тренувався, які вправи виконував, скільки підходів і повторень зробив та з якою вагою. На основі цих даних система відстежує особисті рекорди для кожної вправи.

ER-модель включає в себе сутності (користувач, тренування, вправа, виконання вправи) та зв'язки між ними, включно зі зв'язком "тренування — вправа", реалізованим як окрема сутність (WorkoutExercise), бо він несе власні дані — кількість підходів, повторень і вагу, а не просто поєднує дві таблиці.
