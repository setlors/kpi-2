# User stories

| ID    | Story                                                                                                                           | Requirements     |
| ----- | ------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| US-01 | As a guest, I want to register, so that my workouts are stored under my own account.                                            | R-01             |
| US-02 | As a user, I want to log in, so that I can see my data and nobody else can.                                                     | R-02, R-03, R-04 |
| US-03 | As a user, I want to record a workout with its date and duration, so that I know when I trained.                                | R-05, R-08       |
| US-04 | As a user, I want to add exercises to a workout with sets, reps and weight, so that I can see what I actually did.              | R-06, R-07       |
| US-05 | As a user, I want to look through my past workouts, so that I can compare them with new ones.                                   | R-10             |
| US-06 | As a user, I want a reminder when I have not trained for a week, so that I do not forget about training.                        | R-11             |
| US-07 | As a user, I want an exercise that is already used in my workouts to stay in the system, so that my history does not lose data. | R-09             |
